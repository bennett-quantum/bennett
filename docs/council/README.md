# Councils

A council is three review seats from different vendors (Muse Wonder Full is kept for council seats) on one published
contract change: ISA or dialect spec text, or the reference interpreter. Each seat gets the change, the rubric that fits
(`rubric-impl.md`, `rubric-isa.md`, `rubric.md`) and the review rule in ../process/COMMON.md (round 1 lists blockers; a
round 2 only confirms they are fixed). Commit one `<name>/report.md` per council: verdict per seat, blockers, beads filed.
Prompts and raw outputs stay in the orchestrator's .tmp.
